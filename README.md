# 🎿 Ski123 Live Timing Web

Веб-сервис онлайн-трансляции и интерактивного табло для соревнований по лыжным гонкам и биатлону (интеграция с системой хронометража **Ski123 / SWIDATA**).

---

## 🚀 Возможности

- 🔴 **Реальное время (Live)**: Автоматическое обновление данных каждые 2 секунды без перезагрузки страницы.
- 📱 **Мобильная адаптация**: Идеально помещается на экраны любых смартфонов — на мобильных устройствах клуб и возрастная группа выводятся подстрочником, а отставание показывается прямо под результатом без горизонтального скролла.
- ⏱ **Стартовый протокол**: Отображение всех заявленных спортсменов с плановым временем старта и статусами.
- 📊 **Промежуточные отсечки (круги / этапы)**: Отображение спортсменов, реально прошедших отсечку, включая сплиты участников с последующей дисквалификацией.
- 🏁 **Финишный протокол**: Точные места, результаты, отставания от лидера, а также отображение сошедших участников (`НС`, `НФ`, `ДСКВ`) внизу протокола.
- 🖥 **Оконная панель управления (GUI)**: Запуск, остановка и смена IP-адреса хронометража в один клик без консоли.

```text

        └── app.js         # Динамический рендеринг таблицы на клиенте
```

## 🛠️ Установка и запуск

### 1. Требования
- Установленный **Node.js** (версия 18+ для Win 10/11, либо 13.14.0 для Win 7).
- Работающая программа **Ski123** в локальной сети или на этом же компьютере.

### 2. Клонирование и установка зависимостей
```bash
git clone https://github.com/ВАШ_ЛОГИН/Ski123-Live-Timing.git
cd Ski123-Live-Timing
npm install
```

### 3. Настройка IP-адреса
В файле `config.json` укажите IP-адрес компьютера, где запущен Ski123:
```json
{
  "port": 3000,
  "targetUrl": "http://10.3.226.131/Info",
  "eventCacheTtlMs": 30000,
  "resultsCacheTtlMs": 1500,
  "soapTimeoutMs": 3500
}
```
*(Либо меняйте IP прямо в оконном приложении через кнопку «Сохранить»).*

### 4. Запуск

#### Вариант А: Через графическое окно (рекомендуется)
Дважды кликните по файлу **`Run_App.vbs`** (или ярлыку на Рабочем столе):
- Нажмите кнопку **«▶ Запустить сервер»** — сервер запустится в фоне и сам откроет браузер.
- При закрытии окна сервер автоматически выключится.

#### Вариант Б: Через терминал
```bash
npm start
```
Сервер будет доступен по адресу: `http://localhost:3000` (а также по вашему локальному IP в сети, например `http://10.3.226.131:3000`).
